# OrbitVision Frontend

AI-powered satellite cloud-removal & reconstruction interface, built with React 19, Vite 7, Tailwind CSS v4, and Framer Motion.

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Structure

- `src/components/layout` — Navbar, animated Background, Footer
- `src/components/hero` — Landing hero: headline, CTAs, stat counters, animated Earth
- `src/components/workspace` — Upload → AI processing → Output demo with quality metrics
- `src/components/showcase` — Before/after comparison slider and the 4-stage pipeline
- `src/components/technology` — Model stack, architecture diagram, feature grid
- `src/components/ui` — Shared primitives (Button, Card, Badge, SectionTitle, GlassPanel)
